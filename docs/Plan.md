# Plan

## Problem Statement
Can ML/DL approaches provide meaningful predictions for UK election results? Can they be used with granular polling data and historical data to generate effective seat projections? 


## Steps

1. Build v1 with basic data, train and test. Have a baseline

2. Expand data processing - include Yougov tables

3. Use MLflow to run experiments - explore algorithms and DL architectures to shortlist models

4. Build basic frontend app to visulaise outputs

5. Deploy with streamlit, Huggingface or AWS free tier

6. Automate fresh data updates, improve frontend. Advertise

7. Set up monitoring

8. Tidy documentation, Consider breaking up into microservices

9. Reflect, report, tweet, make a youtube tutorial


## Rules

No AI edits except for frontend dev
Write and maintain tests
